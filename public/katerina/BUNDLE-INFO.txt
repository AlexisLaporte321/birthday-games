IMPLEMENTATION NOTES:
=====================

- No ES6 modules (single bundled file)
- Self-contained IIFE (Immediately Invoked Function Expression)
- All sprites defined inline
- Compatible with simple HTML script tag inclusion
- Delta time not needed (game speed normalized by screen width)
- Debug mode available on localhost (hitboxes, stats)

USAGE:
======

Include in HTML:
<script src="game-bundle.js"></script>

The game will automatically initialize when the DOM is ready and look for
a canvas element with id="gameCanvas".
